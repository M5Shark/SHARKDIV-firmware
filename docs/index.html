SHARKDIV WEB FLASHER

v1.7.24 · no installs, flashes straight from the browser
  1. Use Chrome or Edge on desktop (the flasher needs Web Serial).
  2. Connect SHARKDIV with a USB data cable. If the port doesn't appear: hold BOOT, tap RESET, release BOOT.
  3. Click Connect, pick the serial port, then Install.
  4. Choose _erase + install_ on a new device for a clean start.
If the browser flash fails on your USB bridge, flash over USB with esptool instead — see FLASHING.md.
Firmware: github.com/M5Shark/SHARKDIV-firmware (MIT, based on CiferTech ESP32-DIV). Full 16 MB image — bootloader, partition table and app in one file.
