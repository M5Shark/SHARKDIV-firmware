# SHARKDIV case — 3D print files

Print files for the SHARKDIV enclosure (ESP32-S3 multitool, 2.4" ILI9341
touch display). Original CAD exports, 2026-09-16.

| File | Part |
|---|---|
| `bottom-case.stl` | 底壳 — bottom shell |
| `top-case-dual-color.stl` | 顶壳 (双色) — top shell, dual-color print |
| `light-pipe.step` | 导光柱 — LED light pipe (STEP, machine the size you need) |
| `color-paint.3mf` | 上色文件 — color/paint reference model (3MF) |

Print the top shell in two colors (single STL with color changes at the
layer split) or paint using the 3MF as reference. All parts oriented as
exported; 0.2 mm layers, no supports needed except where noted by your
slicer.
